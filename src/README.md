# Log File Reader

## Overview
This little tool helps you quickly scan through plain text log files. It reads your log file line by line and then gives you a summary of the different log levels it finds, like `INFO`, `ERROR`, and `WARN` messages. It's super handy for getting a quick health check on an application without having to manually dig through thousands of lines of logs.

## Features
-   **Display Full Logs**: Prints the entire content of the specified log file to the console.
-   **Summarize Log Levels**: Counts and displays the total occurrences of `INFO`, `ERROR`, and `WARN` messages.
-   **Simple Interface**: Provides straightforward command-line output for quick log analysis.

## Usage
To use this log file reader, you'll need a Java Development Kit (JDK) installed on your system.

First, make sure the `log.txt` file is in the same directory as your `Main.java` source file, or in the same directory where you'll run the compiled `.class` file.

1.  **Compile the Java code**:
    Open your terminal or command prompt, navigate to the `src` directory, and compile the `Main.java` file:
    ```bash
    javac Main.java
    ```

2.  **Run the application**:
    After successful compilation, run the compiled class:
    ```bash
    java Main
    ```
